用户要结束当前 session，把工作交接给一个**全新的、没有任何本会话上下文**的 agent session。

你的任务：基于当前会话到目前为止的全部上下文，写出**一段自包含的接力 prompt**，让用户直接复制粘贴发给新 session，新 agent 读完就能无缝接着干，不需要回头问你任何问题。

$ARGUMENTS

## 输出要求

- 把接力 prompt 放在一个 **fenced code block** 里（方便一键复制），block 外不要再写多余寒暄。
- 用**第二人称**写给新 agent（“你的任务是……”“当前状态……”），不是写给用户的总结。
- 假设读者对本项目、本任务**一无所知**：所有路径用绝对路径，所有专有名词/缩写第一次出现时点破，别依赖只有本会话才懂的指代（“那个文件”“刚才的改动”都要写清楚具体是什么）。
- 只交接**继续工作真正需要**的信息，砍掉流水账和已经作废的弯路。宁可精准，不要冗长。
- 语言跟随用户：本会话主要用中文就用中文写，用英文就用英文写。

## 接力 prompt 必须覆盖（按此顺序，可按实际取舍，不要硬凑空段）

1. **目标 / 北极星** —— 这个任务最终要交付什么，成功长什么样。
2. **当前状态** —— 已经做完了什么、做到哪一步、现在能跑/不能跑。改了哪些文件（绝对路径）、关键改动是什么。
3. **剩余工作** —— 还差哪些，最好拆成有序、可独立验证的步骤，每步带上 `verify:` 怎么确认做对了。
4. **关键上下文与坑** —— 已经定下的决策及其原因、试过但行不通的路（避免新 session 重蹈）、必须遵守的约定、隐藏依赖、环境前提。
5. **落地入口** —— 新 session 上手第一步该读哪些文件 / 文档 / SSOT（绝对路径），该从哪个目录、哪条命令开始。若有 `docs/working-plan/README.md`、项目 `README.md`/`AGENTS.md`、`CLAUDE.md` 等约定文件，明确点名让它先读。

## 动手前

- 如果当前会话上下文里**缺关键信息**（比如根本没说清目标、或状态含糊到没法交接），先向用户点名缺什么、简短确认，再生成 prompt——别硬编。
- 如果 `$ARGUMENTS` 指定了交接范围，就聚焦那个范围，其余只做必要铺垫。
