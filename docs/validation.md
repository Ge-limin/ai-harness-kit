# 验证记录

本地审阅版的验证范围：

- 随包文件与 HTML 内嵌文本一致，来源记录的目标均存在。
- 公司资料仅保留 GitHub 链接；正文、数据源标识、执行机地址和内部运行参数未包含在附件中。
- JSON、TOML 和 YAML 配置可解析；模型、推理强度、自主执行模式、插件开关与并发选择保持一致。安装路径与凭据使用明确占位值。
- 文件列表默认显示文档，支持配置、脚本、目录筛选和搜索；阅读、复制、下载及返回指南通过浏览器验证。
- 中英文页面在桌面和手机视口检查，无页面横向溢出或 JavaScript 异常。
- 公司链接的可用状态见 [SOURCES.md](SOURCES.md)。私有仓库访问需要权限，待同步资料由源仓库维护。

构建入口：`python3 tools/build-guide.py`。规范导出工具的单元测试与 dry-run 已验证，未写入客户端设置。配置模板、公司命令和部署未执行；安装后运行能力仍需在目标环境验证，见 [DEPENDENCIES.md](DEPENDENCIES.md)。
